# Résumé data

Career data from the old web CV, kept for a future résumé (for example a
Typst document, which can read these files with `yaml()` and Markdown front
matter by hand). Nothing here is built into the site.

- `positions.yaml`, `education.yaml`: one entry per role or degree.
  Quote any text containing ` #` or `: `.
- `publications/`: one file per publication; the body is the abstract.
  `nlp-first-order-logic.md` still needs its year.
